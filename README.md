# GTA VI Trophy Guide & Tracker

An offline trophy guide and progress tracker for Grand Theft Auto VI on PlayStation 5. All 55 official trophies with step-by-step guides written for this app, a two-run roadmap to the platinum, missable warnings, kind filters, a spoiler setting that hides unearned story trophies, and progress export/import - everything saved in the browser, nothing fetched from the network.

- **Tracker** - the full list with grade colours, kind tags, MISSABLE badges, filters, search and a live progress bar.
- **Roadmap** - eight ordered stages to the platinum, with a missable-risk summary on top.
- **Guide pages** - every trophy opens a page with numbered steps, cited sources, prev/next and a mark-earned button.
- **Settings** - spoiler toggle, JSON export/import and a progress reset.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no install, no network access - the app is static files under `app/`.
